## 🌐 Quick Deploy to GitHub Pages (Under 2 Minutes)

Since your GitHub account is **`muhammadmaksud3774`**, you can deploy this website to GitHub Pages easily:

### Step 1: Initialize Git & Commit
Open your terminal in `C:\Users\maksud.belim\.gemini\antigravity\scratch\developer-portfolio` and run:

```bash
git init
git add .
git commit -m "Add Maksud Belim portfolio website"
```

### Step 2: Create Repository & Push
1. Go to [GitHub New Repository](https://github.com/new).
2. Name the repository `portfolio` (or `muhammadmaksud3774.github.io`).
3. Run:
```bash
git branch -M main
git remote add origin https://github.com/muhammadmaksud3774/portfolio.git
git push -u origin main
```

### Step 3: Enable Free Hosting
1. Go to your repository **Settings** -> **Pages**.
2. Under **Build and deployment** -> **Branch**, select `main` and `/ (root)`.
3. Click **Save**.

Your portfolio will automatically be published and publicly accessible at:
👉 **`https://muhammadmaksud3774.github.io/portfolio/`**
